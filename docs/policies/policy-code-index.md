# SHRS Policy Code Index

*Establishes the coding standard for the entire governance library —
the 9 live, published policies (`pages/policies.html`) and the 26
policy/framework documents drafted in `docs/policies/` across Phases
A–F — per the Governance & Policy Redevelopment Directive, Phase E, and
the Website Publication Requirement, Phase F.*

**Owner:** Board of Trustees (the standard itself); each policy's own
Owner maintains its individual code assignment.
**Review cycle:** Annual, alongside the Governance Master Register.

## The scheme

**Prefix + two-digit number.** For the nine live policies, the number
preserves the position the policy already holds in its existing Roman
numeral (so VI → 06, VII → 07, VIII → 08) — the live site's own
existing category groupings (Academic / Conduct & Discipline / Safety
& Welfare / Administrative) map directly onto four of the prefixes
below, so nothing about the live policies' identity changes, only how
it's presented. For documents that exist only in the governance
library (no live-site precedent), numbering is sequential within the
category, starting after any live policy already holding a number in
that family.

| Prefix | Category | Matches Governance Master Register section(s) |
|---|---|---|
| **GV** | Governance | §1 Governance |
| **AC** | Academic Affairs | §2 Academic Affairs |
| **SD** | Student Affairs | §3 Student Affairs |
| **PA** | Parent Affairs | §4 Parent Affairs |
| **SW** | Safeguarding & Welfare | §5 Safeguarding + §9 Health, Safety & Welfare |
| **HR** | Human Resources | §6 Human Resources |
| **FN** | Finance & Administration | §7 Finance & Administration |
| **IT** | Technology & Digital Campus | §8 Technology & Digital Campus |
| **IQ** | Islamic & Qur'an Education | §10 Islamic & Qur'an Education |

## Publication Status classification principle

Per the Website Publication Requirement: **no governance document
exists only in the repository unless intentionally classified as
internal-only.** The classification below follows common real-world
institutional practice, not an arbitrary default:

- **Public** — family/student-facing documents, and documents many
  comparable schools publish in full as a matter of transparency and
  (for safeguarding and data-protection specifically) common
  expectation: safeguarding, conduct, admissions, boarding, data
  protection, AI usage, and the foundational governance charter.
- **Internal** — staff HR matters, internal financial-control
  specifics, and technical security detail where publishing exact
  parameters (lockout thresholds, approval amounts) would be
  counterproductive or simply isn't information a parent or student
  needs.
- **Internal (meta)** — evaluation/framework documents that assess
  *other* policies rather than governing conduct themselves (the three
  Governance Frameworks) — these inform the Board, not the public.

This classification is a proposal for Board confirmation, not a final
determination — a real institution's legal/comms function should
confirm each one, particularly the borderline cases noted inline.

## Meta / tracking documents — not policies, no code assigned

Governance Master Register, Governance Resolution Register, SHRS
Institutional Readiness Report, Governance Completion Report, the Phase
A–F dependency reviews and consistency audits, and this index itself.
These govern the governance process, not institutional conduct, and
are internal by nature — publishing an internal audit trail alongside
the polished policies it produced would confuse rather than inform a
family reading the site.

## Publication actions taken (Phase F)

**All 14 Public-classified retrofitted documents are now physically
published** to `pages/policies.html` and `pages/policies.ar.html`,
each as a new accordion entry with a Policy Information metadata block
(Code, Version, Owner, Approval Authority, Review Cycle) and a
substantive summary, following the pattern proven for SW-06/07/08:
Child Protection & Safeguarding Policy (SW-01, published first as the
single highest-priority document), Academic Regulations (AC-02),
Student Code of Conduct (SD-02), Student Handbook (SD-03), Boarding
Regulations (SD-04), Parent Handbook (PA-02), Admissions Policy
(PA-05), Emergency Response Plan (SW-09, with the site-specific-detail
caveat above), Data Protection & Privacy Policy (IT-02), Acceptable Use
Policy (IT-03), Records Retention Policy (IT-04), AI Usage Policy
(IT-05), Hifz Regulations (IQ-01), and Ijazah Governance Framework
(IQ-02). Each publication was individually rebuilt (`node
scripts/build.js`), verified for HTML div-tag balance, and verified for
the new policy code's presence in both the English and Arabic built
output before being committed and pushed — one document at a time, not
batched and assumed correct.

**What this closes:** every document this project has drafted and
classified Public is now genuinely public — a family reading
`pages/policies.html` or `pages/policies.ar.html` today sees the same
governance depth this repository has been building since Phase A, not
a partial subset of it. The gap named in the Governance Completion
Report ("thirteen more documents classified Public but not yet
physically added") is now closed.

**What remains open:** GV-01 (Constitution & Governance Charter) and
SW-02 (Designated Safeguarding Lead Framework) are still v1.0 — not yet
retrofitted to the full 13-section architecture (Tier 3 work, per the
original retrofit directive) — so they remain undrafted-at-depth rather
than unpublished; retrofitting them is a prerequisite to publishing
them at the same standard as the 14 documents above, not a publication
task in itself. As new Public-classified documents are drafted or
retrofitted going forward, this same one-at-a-time publish-and-verify
discipline should apply — this index's Publication Status column is
the tool that tracks it, not a one-time label.
