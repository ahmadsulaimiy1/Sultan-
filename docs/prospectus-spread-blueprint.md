A confirmed grid system (margins, baseline grid, column structure) to

built against. Two real dependencies must resolve before Deliverable
#5 (Final Production) can complete: the `NEW PHOTOGRAPHY NEEDED` flags
on spreads 6, 8, and 15, and the `[FIGURE PENDING]` markers on spreads
