# Audio

## bismillah.mp3

Place a recitation of **بسم الله الرحمن الرحيم** here, named exactly
`bismillah.mp3`. `js/bismillah.js` plays it once per browsing session,
on the visitor's first interaction with the page, with no player and
nothing shown on screen.

Guidance:

- Keep it short — the basmala alone, 3–6 seconds. It is an opening, not
  a track.
- Export mono, 96–128 kbps. The file should sit comfortably under 100 KB
  so it never delays anything.
- Trim the silence at both ends, and normalise gently. The player already
  attenuates to 55% volume.
- Use a recitation the school has the right to publish.

Until the file is present the site simply stays quiet — the player fails
silently by design and nothing appears on screen.
