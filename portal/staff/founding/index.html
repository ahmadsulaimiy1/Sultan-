Founding Officers

This opens the school’s portals for the first time. Until an officer exists in each seat, the Registrar portal, the Newsroom, the Founder Dashboard, Safeguarding and the Admin Centre have nobody who can sign into them.

Before you begin

Read this once

Nothing here is filled in for you. Every name, staff number and email is typed by the school. No officer of this institution is named by software, and no name on this page came from anywhere but your keyboard.

No password is set here. Each account is created without one and issued a single-use activation link. Give that link to the person; they choose their own password. Nobody — not the school, not this page — ever sees it.

The token below is held in memory only. It is never stored, never written to this device, and gone the moment you reload. It is your PORTAL_SYSADMIN_TOKEN from Cloudflare. Treat it as you would a master key: once the Registrar and Head of Schools accounts exist, work in the Admin Centre instead and you should not need this page again.

Set in Cloudflare Pages → Settings → Variables and secrets. If it is not set there, nothing on this page will work — and that is correct: an open version of this page would let a stranger appoint themselves Registrar.

The seats

Open the ones you need

You do not have to open all of them. Start with the Registrar and the Head of Schools — between them they reach every portal built so far. Each seat says what it opens. Role scope is left school-wide for now; narrow it in the Admin Centre once you have settled which institutions each officer covers.
