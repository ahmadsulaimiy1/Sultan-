Graduation Records — 8 August 2026 Ceremony

Graduation Information Submissions

Guardians submit these from their own dashboard — nothing here is typed in by staff. Review a submission, request a correction if something looks wrong, then mark it verified once the details and results are confirmed. Marking a record verified starts the full institutional Graduation Approval Workflow — Academic, Examinations, Finance, Disciplinary, Library, ICT, Principal, both Vice Principals, and the Founder where required — tracked on the Graduation Control Centre →, not here. A record locks itself automatically once every stage clears.

Open Graduation Control Centre →

Graduation Register

The full ceremony roster for one graduation session — every locked record, in one institutional publication. This is not an individually-verifiable credential: it carries no reference number, seal, or verification code of its own (each graduate's own documents carry those separately).

Pending Testimonial & Character Certificate Approvals

A Testimonial or Character Certificate can only be requested from a locked graduation record (see the record's own action row above) and only becomes a real, issued document once the student's own Principal/Head Teacher approves it here — a Registrar cannot approve their own request.

Lifetime Verification History

Every time a document's reference number has been checked at the public verification page, since the document was issued — the anomaly-review purpose this exists for is repeated or suspicious checks against one document.
